# Granergize WebApp
The Granergize WebApp allows consists of a frontend for browsing and comparing energy consumption data of different buildings and a backend for fetching data from the Granergize Knowledge, converting the data to JSON and serving it to the frontend.

![Granergize WebApp](./screenshot.png)

## Pre-requisites
- [Deno2](https://deno.land/) installed

## Setup
- Clone the repository
- Run `deno install` to install the dependencies
- Run `deno run --allow-net --allow-read serve`
- Open `http://localhost:8000` in your browser
